NXClaw
Autonomous Sandboxed Terminal Agent

System Overview

NXClaw is a lightweight, zero-dependency, hacker-style coding agent operating entirely inside a secure terminal sandbox. Engineered without heavy web frameworks, it utilizes the native Python standard library to run, evaluate, write, and patch files autonomously.

Powered by advanced reasoning models—including GPT-5.5, Claude Fable 5, and local Ollama instances—NXClaw handles complex developer pipelines by recursively running commands, compiling test scripts, reading runtime environments, and self-correcting its output based on terminal feedback.

Operational Runbook

Deploy the agent and initiate interaction directly through standard command terminal utilities.

Step 1: Bootstrap the Core Environment

Execute the downloaded source or compiled target to configure your API endpoint, backend, and sandbox workspace:

# If running from the raw Python source:
$ python3 nxclaw.py

Step 2: Reference Local Files with @ Syntax

When asking tasks, flag workspace files using the @ operator. NXClaw will automatically read the file contents, inject it into the LLM context, and strip the identifier during disk operations:

> Please refactor the error handling in @app.py and run the local compiler to verify.

Step 3: Leverage Slash Instructions

Query or modify workspace states directly from the prompt line using integrated slash commands:

  • /ls — Scan and print directory structures inside the safe workspace.
  • /rm {file} — Safely delete specified target files inside the sandbox.
  • /open {file} — Launch the workspace file in your OS's native text editor.
  • /auto-confirm — Toggle autonomous execution mode to skip user command prompts.
  • /clear — Purge conversation history to reset context.
