Security & advanced settings

Vault design: random 256-bit wallet encryption key → AES-256-GCM encrypted vault; Argon2id(password, random salt) → AES-GCM wraps the wallet key. Changing password only rewraps the wallet key. Auto-lock: 5 minutes.

Discovery currently scans BIP44/49/84/86 receive and change chains with a gap limit of 20. Be careful importing a wallet with an unusually large gap; change the account and rescan as needed.

NeuralNexusLab Bitcoin Wallet is a self-custody browser hot wallet. Review source and test on Testnet4 before use. A compromised browser, device, extension, or supplied page can steal unlocked funds; this is not a cold-storage or hardware-wallet replacement.
